ActionDiT 逐层低秩结构

每层的 64 个 action token 各是一个 1024 维向量。这里看这些向量在单个任务和三个任务合起来时是不是集中在一个低维子空间里，以及用均值 + 协方差前 k 个主方向构成的椭球能不能盖住没见过的 episode。

数据LIBERO-10 任务 0 / 4 / 9，每个任务随机 5 个 episode，每 10 帧取 1 帧，开环（数据集帧）
样本
采集点action encoder 输出 + 5 个 double 层 + 20 个 single 层之后的残差流，去噪步 0 / 5 / 9
推理fp16，RTX 5090，eager 与 CUDA graph 的 action 完全一致

结论

    有效秩随层的变化

    有效秩 = exp(熵)，熵取自中心化后 token 矩阵奇异值的归一化分布。"三任务合并（同样本数）"从三个任务里各抽三分之一，使 token 数等于一个任务，用来和单任务直接比较。

    去噪步

    k99：达到 99% 方差需要的主方向数（三任务合并）。纵轴是维数，满维是 1024。

    低秩有多少来自少数大幅值通道

    single 层的第一主方向主要落在约 8 个方差特别大的通道上。去掉第一主方向，或者先把每个通道标准化到单位方差再算，有效秩会变大。按方差算时空间很低维；按"每个通道同等重要"算时，后面的 single 层就不算很低维了。

    去噪步

    协方差低秩椭球

    椭球 = 均值 μ + 协方差前 k 个主方向 Uk、方差 Λk；半径 r 取训练 token 在子空间内马氏距离的 95 分位。按 episode 留一：每次拿出一个 episode，用其余数据拟合。覆盖率 0.95 说明椭球能推广到新 episode。三种拟合方式：本任务的另外 4 个 episode；三任务合并（同样留出这个 episode）；另一个任务的全部 episode。

    单层的谱和二维投影

    去噪步 9。左：协方差特征值占比（对数轴，前 96 个）。右：每个任务随机 400 个 token 投到三任务合并的前两个主方向上，椭圆是各任务的 2σ 协方差椭圆。token 沿第一主方向分成两簇，对应这个 token 预测的夹爪是开还是合（去噪步 9，相关系数 |r| = 0.99，double4 / single0 / single9 / single19 都是如此），所以 2σ 椭圆会跨过两簇。

    平面以外的结构

    同一层、同一批 token。左：PC2–PC3 投影，避开了编码夹爪的 PC1，椭圆是各任务的 2σ 协方差椭圆。右：PC1–PC3 三维散点，拖动可旋转；线框是各任务的 2σ 协方差椭球（画出三个主截面）。三个任务在某一层的 PC2–PC3 上重叠，说明区分任务的方向排在 PC3 之后；切到"夹爪"着色可以看到 PC1 上开、合两簇。

    只看机械臂：去掉夹爪方向

    在每一层（每个去噪步）把夹爪方向投影掉：u = 夹爪"开"的 token 均值 − "合"的 token 均值，归一化后从每个 token 里减去它在 u 上的分量。之后前 5 个主方向和夹爪值的相关都不超过 0.006，也不再分簇。在剩下的部分上重算有效秩和椭球，并检验低维子空间能不能解释机械臂动作：按 episode 留一，用训练 token 的前 k 个主方向坐标做线性回归，预测这个 token 自己的 xyz + rpy 六维动作（模型输出），在留出 episode 上算 R²（六维平均）。

    局限

    • 3 个任务 × 5 个 episode，366 个样本；单模型、fp16、数据集帧开环推理，不是闭环轨迹。
    • 有效秩和 k99 都按方差加权，受少数大幅值通道主导；标准化后的有效秩要另看。
    • 每个任务只有 4 个训练 episode，k = 128 时尾部方向的方差估不准，本任务椭球的覆盖率因此下降。
    • 样本层面（64×1024 展平）的有效秩受样本数限制（每任务 92–141 个），只作参考，见数据表。
